# data/

Plaats hier `.bpmn`-bestanden. Deze map is **niet** onder version control
omdat bronbestanden organisatie-specifiek / vertrouwelijk kunnen zijn.

Voorbeeld:

```
data/
├── proces_A.bpmn
├── proces_B.bpmn
└── proces_C.bpmn
```

Draai vervolgens vanuit de project-root:

```bash
python src/main.py
```
